CB File Hub 将你的文件、媒体和远程存储汇集到一个应用中。

- 使用标签页浏览文件夹，支持分屏视图、固定常用位置并恢复工作区。
- 可选列表、网格、详细信息、树形或分栏视图。支持搜索、排序和多选文件，大型文件夹按需加载。
- 查看照片、编辑图片并浏览视频库。播放媒体时支持字幕和音轨；桌面端支持画中画。
- 使用标签、相册和自动相册规则整理收藏。
- 连接 SMB、FTP、SFTP 和 WebDAV 存储。管理 SSH 连接并使用内置终端。
- 将 .torrent 文件和磁力链接集中到一个可搜索的库中。合并重复项、复制磁力链接并选择文件的存储位置。
- 在桌面端下载种子，选择保存位置，暂停和继续。从其他客户端导入已保存的种子，包括 Windows 上的 qBittorrent 备份。
- 让 CB Agent 帮你查找和整理文件。桌面端可选使用兼容的本地 GGUF 模型。
- 使用 Windows 磁盘清理工具检查并删除不需要的文件。
- 浏览并解压 ZIP 及其他受支持的压缩包。额外的 7z/RAR 功能使用 Windows 上已安装的 7-Zip。
- 备份设置和标签，可使用 Google Drive、Dropbox 和 OneDrive 集成。
- 选择浅色或深色主题、强调色以及界面语言。

功能因平台而异。网络、云备份和 AI 服务可能需要账户或额外设置。
